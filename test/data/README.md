# Decoder test vectors

Generated by `tools/gen_test_vectors.py` (numpy + soundfile) and dedicated to the public domain under CC0 1.0. Regenerate after changing the script:

```bash
python -m pip install --user numpy soundfile
python tools/gen_test_vectors.py
```

`vectors.txt` lists every file with its expected codec, format, length and the CRC-32 of the decoded Q31 output. The tests in `test/test_decoders_*.c` read it.

| Files | What they cover |
|---|---|
| `wav_s16_44k.wav` | reference signal (997 Hz sine left, 50 Hz–8 kHz sweep right), unknown and odd-sized chunks before `data` |
| `wav_s24_96k_ext.wav`, `wav_s20in24_48k_ext.wav` | WAVE_FORMAT_EXTENSIBLE, 24-bit and 20-bit valid in a 24-bit container |
| `wav_f32_44k.wav`, `wav_f64_48k_mono.wav` | IEEE float with values beyond full scale, infinities and NaN (saturate, NaN to 0) |
| `wav_u8_22k_mono.wav`, `wav_s32_48k_rf64.wav` | 8-bit unsigned mono, RF64 with `ds64` sizes |
| `aiff_*.aiff`, `aifc_*.aifc` | big-endian PCM, `sowt`, `fl32`, `SSND` before `COMM` with a non-zero offset |
| `flac_*.flac` | 16/44.1, 24/96, FLAC behind an ID3v2 tag |
| `mp3_vbr_44k.mp3`, `mp3_cbr_44k.mp3`, `mp3_tagged_44k.mp3` | Xing+LAME (VBR), Info+LAME (CBR), ID3v2 + APEv2 + ID3v1 around the frames |
| `mp3_lsf_22k_mono.mp3`, `wav_s16_22k_mono.wav` | MPEG-2 Layer III (576 samples per frame) mono and its 16-bit source |
| `ogg_44k.ogg`, `ogg_bigcomment_44k.ogg` | Vorbis, and the same stream with a 150 KB comment packet over several pages |
| `gap_ref.wav`, `gap_[ab].flac`, `gap_[ab].mp3` | one continuous 1 kHz sine split at sample 22383 (not a frame boundary) |
| `dsd64_1k.dsf`, `dsd64_1k.dff`, `dsd64_mono_msb.dsf` | 1 kHz tone from a 2nd-order sigma-delta modulator: DSF LSB-first, DFF, DSF MSB-first mono |
