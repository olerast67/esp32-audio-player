# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in issues, pull requests and discussions of esp32-audio-player is expected to follow it.

Report unacceptable behaviour to the maintainer, [@olerast67](https://github.com/olerast67), through the contact on the GitHub profile. Reports are handled confidentially.
